Evolution Rings — Prototype (HTML5 Canvas)

Как запустить:
1) Распакуй zip в любую папку
2) Открой index.html двойным кликом (или через любой локальный сервер)

Управление:
- Клик по кольцу: выбрать
- ⚡ Ускорить: увеличивает скорость выбранного кольца (за EP)
- ➕ Увеличить Δ: увеличивает прирост множителя (за EP)
- 🌟 Завершить эпоху: доступно, когда EP >= Target (престиж)

Где баланс:
game.js → блок "Game params (балансируй тут)".

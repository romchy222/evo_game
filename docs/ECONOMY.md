# Economy & Progression (Evolution Rings)

## Основные ресурсы
- **EP (Energy Points)** — основная валюта, получаемая за замыкание орбит. Тратится на апгрейды орбит и контроль инфляции.
- **GP (Gene Points)** — мета-валюта за престиж. Тратится на постоянные улучшения.
- **Essence** — редкая валюта за испытания, идеальные циклы и оффлайн-прогресс. Тратится на бустеры и косметику.

## Источники / стоки
**EP источники**
- Замыкания орбит: зависят от произведения орбит, бонусов, синергии и инфляции.

**EP стоки**
- Апгрейды скорости и Δ выбранной орбиты.
- Срезы инфляции.
- Синергия.

**GP источники**
- Престиж: `gpGain = prestigeBaseGP + floor(epoch / prestigeGpStep)`.

**GP стоки**
- Перманентные ген-апгрейды: x-множители, стабилизация инфляции, стартовые орбиты, автопокупка, ядро EP.

**Essence источники**
- Испытания, идеальные циклы, редкий дроп за замыкания, оффлайн-симуляции.

**Essence стоки**
- Временные бустеры (x2 время, стабилизатор инфляции).
- Косметика.
- Усиление редкого дропа.

## Формулы
### EP за замыкание
```
rawGain = ((M * prestigeBonus * gainMul) + 1) * ringCountBonus / inflation
boostedGain = rawGain * bonus.epGain
gain = softcap(boostedGain, softcap.epGain, softcap.epDiv)
```

### Инфляция
```
inflLinear = baseInfl * ringFactor * pathBonus * modifierBonus * bonus.infl
inflLinear *= (stabilityShield ? 0.7 : 1)
inflation *= (1 + inflLinear * dt)
```

### Стоимости
```
cost = base * growth^level * indexGrowth^ringIndex * bonus.cost
```

## Ограничители
- Softcap EP: начиная с `softcap.epGain`, прирост сглаживается.
- Рост инфляции усиливается при большом числе активных орбит.
- Оффлайн-прогресс ограничен по времени и числу шагов.

## Системные механики
### Overdrive
- Кнопка ускорения даёт x2 к добыче на короткое время.
- Накопленный перегрев включает штраф на скорость/доходы.

### События
- Солнечные вспышки, астероидные поля и аномалии дают временные модификаторы.

### Экспедиции
- Корабль отправляется на 2–10 минут и возвращается с наградами и артефактами.

### Контракты
- 3 активных задания, обновляются по таймеру.
- Награды: EP, GP, Essence.

## Конфиги
См. `game.js`:
- `cfg.progression` — целевые значения престижа.
- `cfg.pricing` — кривые цен.
- `cfg.softcap` — ограничения на EP.
- `cfg.offline` — оффлайн-симуляция.
- `cfg.overdrive`, `cfg.events`, `cfg.expeditions`, `cfg.contracts` — активные механики.

## Dev-панель
Dev-панель в опциях позволяет выдавать валюту, ускорять время и сбрасывать прогресс.
Включается кнопкой `Dev: выкл/вкл` и сохраняется локально.
